# Доработки

Найдено при установке публичного образа с карты 16 октября 2026 года.

## Оболочка

- **`PATH` в Терминале без `sbin`.** foot запускает не login-оболочку, поэтому
  `/etc/profile` не читается: `PATH=/usr/local/bin:/usr/bin:/bin`. `doas`
  берёт `PATH` вызывающего, и `doas rc-service …` пишет «command not found»;
  работает только полный путь (`doas /sbin/rc-service`). Вероятно, хватит
  `shell=/bin/sh -l` в `rootfs/foot.ini` или `setenv { PATH=… }` в правиле doas.
- **На экранной клавиатуре нет `>`** (а значит, и перенаправления в файл).
  Проверить раскладку `wvkbd/config.b8k.h` на `<`, `>`, `|`, `&`, `~`.
- **USB-клавиатура не работает.** Порт USB работает только как устройство
  (gadget), режима хоста (OTG) в ядре нет.

## Доступ и права

- **Пустой пароль `user` при `doas` для wheel.** По исходникам OpenDoas пустой
  хеш с пустым вводом не сходится, но на планшете это не проверено. Проверить
  и, если пускает, просить пароль при первом запуске.
- **В публичный образ не попасть по SSH,** пока в Терминале не задан пароль
  или не положен ключ. Описать это в `INSTALL.md`.

## Wi-Fi

- **Гонка при загрузке.** `00-b8k-modules.start` и `b8k-netwatch` одновременно
  перезагружают `wlan_mt6628`; `modprobe` висит в состоянии D, а netwatch
  перезагружает драйвер только один раз. Netwatch должен ждать конца
  загрузочной перезагрузки и повторять с паузами.
- **Большие передачи роняют Wi-Fi** (известно, см. CLAUDE.md, «Wi-Fi hangs»).
- **После сна Wi-Fi не всегда возвращается** (16 октября после погасания
  экрана понадобилось включить его заново).
